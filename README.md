# Velvet Pour 
### An Interactive Cocktail Recipe Experience

Velvet Pour is a responsive cocktail recipe website that combines elegant visual design with practical, interactive features. Inspired by the atmosphere of cocktail bars, 
the project offers a modern way to discover cocktails, explore recipes and learn how to prepare drinks at home.

The goal was to create a visually appealing and user friendly experience where users can easily find cocktails based on their preferences or available ingredients.

## Features

- **Cocktail Discovery:** Browse a collection of 12 cocktail recipes with photographs, descriptions and preparation details.
- **Search & Filtering:** Search by cocktail name or ingredient and filter recipes by category.
- **My Bar:** Select ingredients available at home to discover which cocktails can be prepared and identify missing ingredients.
- **Interactive Mixing Guide:** Follow step-by-step instructions with progress tracking.
- **Serving Calculator:** Adjust ingredient quantities based on the number of servings.
- **Saved Recipes:** Save favourite cocktails using localStorage, allowing them to remain available between visits.
- **Responsive Design:** Layouts adapt to desktop, tablet and mobile screens.
- **Animations:** Subtle transitions and scroll animations enhance the browsing experience.

## Technologies Used

- **HTML** – Semantic structure and accessibility
- **CSS** – Styling, responsive layouts, transitions and animations
- **JavaScript (Vanilla JS)** – Interactive functionality, DOM manipulation and event handling
- **localStorage** – Persistent storage of saved recipes and selected ingredients

No frontend frameworks or backend services were currently used.

## Design & UX Approach

Velvet Pour follows a dark, editorial visual direction inspired by sophisticated cocktail lounges.

The design focuses on:

- Clear navigation and intuitive interactions
- Strong visual hierarchy and cocktail photography
- Consistent typography, colours and spacing
- Responsive layouts across screen sizes
- Readable recipe instructions and ingredient measurements
- User feedback through interactive states and progress indicators

The aim was to balance aesthetics with usability, ensuring the website is both visually engaging and easy to navigate.

## Getting Started

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using the **Live Server** extension.

No additional installations or dependencies are required for the JavaScript functionality. An internet connection is needed to load the Google Fonts.
