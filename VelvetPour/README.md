# Velvet Pour

Stack used: HTML, CSS, Vanilla JS.

## Main features
- 12 cocktail recipes with real imagery
- Search and category filtering
- Saved recipes using localStorage
- Ingredient matcher (“My Bar”)
- Interactive step-by-step mixing mode
- Responsive design for desktop, tablet and mobile
- Clean, readable code (not minified)

## Open the project
1. Open the `VelvetPour` folder in VS Code.
2. Open `index.html` directly or use the Live Server extension.
3. Make edits in `styles.css`, `script.js` or `data.js`.

## File structure
- `index.html` → website structure
- `styles.css` → site styling and responsive layout
- `data.js` → cocktail recipe data
- `script.js` → interactions and UI logic
- `assets/images/` → provided image assets
